# ☘️ 《钓客空军自嘲谣》

五更摸黑赴野塘，\
打窝忙，线飞扬。\
十斤饵料，喂饱水中王。\
浮漂稳坐如老僧，鱼何在，问斜阳。

钓友群发巨物照，三斤鲫，五尺鲂。\
低头瞅桶，半尾白条僵。\
钓遍江河皆是水，杆未弯，心已凉。

调漂八十一难后，铅坠歪，子线伤。\
蚯蚓红虫，未及献龙王。\
收竿怒买电磁炉，涮火锅，慰愁肠！
