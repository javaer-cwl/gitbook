## 《码农浮生自嘲赋》

十年寒窗苦作舟，\
敲键盘，夜未央。\
万行逻辑，漏洞暗中藏。\
纵使测试全通过，需求变，又白忙。

产品经理画大饼，功能增，期限荒。\
晨会复盘，计划总成殇。\
技术债务堆成山，秃了头，泪两行。

晨昏颠倒无休止，颈椎痛，鼠标僵。\
注释如谜，交接似猜盲。\
若问此生何所愿，删库跑，归故乡。
